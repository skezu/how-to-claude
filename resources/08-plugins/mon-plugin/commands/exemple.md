# Exemple

Tu es invoqué via `/mon-plugin:exemple` (ou `/mon-plugin exemple`).

1. Confirme que le plugin `mon-plugin` est bien chargé.
2. Liste les composants disponibles dans ce plugin (commandes, agents, skills, hooks).
3. Si l'utilisateur a passé des arguments, affiche-les : $ARGUMENTS
